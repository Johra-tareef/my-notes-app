
# My Notes App (React)

A simple and responsive notes / todo application built with React as part of a front-end development program.

The project demonstrates state management, component-based architecture, and basic user interaction handling.

---

## Features
- Add new tasks
- Delete tasks
- Mark tasks as completed
- Simple and responsive UI

---

## Technologies
- React
- JavaScript
- HTML
- CSS

---

## How to run the project

npm install  
npm start

---

## Purpose of the project
This project was built to practice React fundamentals, including components, state management, and user interface design.
